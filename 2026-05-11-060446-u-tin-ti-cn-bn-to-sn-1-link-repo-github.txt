  ┌─────────┬───────────────────────────────────────────────────────────────┐
  │  Việc   │                         Ví dụ thực tế                         │
  ├─────────┼───────────────────────────────────────────────────────────────┤
  │ Gọi API │ Bạn nói "lấy dữ liệu thời tiết hôm nay" → trợ lý tự kết nối   │

  ├─────────┼───────────────────────────────────────────────────────────────┤
  │ Dùng    │ Giống như cắm thêm "thiết bị ngoại vi" vào máy tính — ví dụ   │
  │ MCP     │ cắm thêm Google Drive, Notion, Slack để tôi có thể đọc/ghi    │
  │         │ trực tiếp vào đó                                              │
  ├─────────┼───────────────────────────────────────────────────────────────┤
  │ Chạy    │ Bạn nói "tạo repo GitHub mới" → trợ lý tự chạy lệnh gh thay   │
  │ lệnh    │ bạn, không cần bạn mở terminal                                │
